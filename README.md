# Netflix_PowerBI_Dashboard

📊 Netflix Data Analysis Dashboard (Power BI)
📌 Project Overview

This project analyzes a Netflix dataset using Power BI to explore content distribution, growth trends, and genre popularity across different countries.

The dashboard provides insights into Netflix's global content strategy and helps understand patterns in movie duration, genres, and content growth over time.

📂 Dataset

The dataset contains information about Netflix titles including:

Title

Type (Movie / TV Show)

Director

Country

Release Year

Duration

Genre

📈 Dashboard Insights

Total Netflix titles analyzed: 5185

Average movie duration: 103 minutes

Content available in 175 countries

Rapid growth in Netflix content after 2015

Drama and International genres dominate the platform

🛠 Tools Used

Power BI – Data Visualization

Excel / CSV Dataset – Data Source

Data Cleaning & Modeling

📊 Dashboard Features

Content growth trend over time

Titles distribution by country

Genre popularity analysis

Movies by duration

Titles by directors
